================================================================================
  SGLang MiniCPM-SALA Execution Roadmap
  Model: MiniCPMSALAForCausalLM | Quant: GPTQ-Marlin int4 | KV: fp8_e5m2
  Attention: FlashInfer + HybridLinearAttnBackend (minicpm4 + lightning layers)
================================================================================

Launch command:

  export SGLANG_SPARSE_PREFILL=1   # only effective in sglang_sala_flashinfer variant, NOT sglang_sala_cp

  python -m sglang.launch_server \
    --model ... --quantization gptq_marlin --kv-cache-dtype fp8_e5m2 \
    --attention-backend flashinfer --disable-radix-cache \
    --chunked-prefill-size 32768 --mem-fraction-static 0.82 \
    --max-running-requests 64

Flag effects:

  ┌────────────────────────────────┬──────────────────────────────────────────────────────────────┐
  │              Flag              │                            Effect                            │
  ├────────────────────────────────┼──────────────────────────────────────────────────────────────┤
  │ --quantization gptq_marlin     │ Model weights loaded as GPTQ, repacked to Marlin int4 format │
  │ --kv-cache-dtype fp8_e5m2      │ KV pool allocated as float8_e5m2 (saves ~50% VRAM vs fp16)   │
  │ --disable-radix-cache          │ Uses ChunkCache instead of RadixCache (no prefix sharing)    │
  │ --attention-backend flashinfer │ FlashInfer kernels for attention                             │
  │ --chunked-prefill-size 32768   │ Prefill split into 32K-token chunks per step                 │
  │ --mem-fraction-static 0.82     │ 82% of GPU memory for KV cache pool                          │
  │ --max-running-requests 64      │ At most 64 concurrent decode batches                         │
  └────────────────────────────────┴──────────────────────────────────────────────────────────────┘

All file paths relative to: /opt/oldMoney-Project/sglang_sala_cp/python/sglang/
(or sglang_sala_flashinfer/sglang/ for the sparse prefill section)
