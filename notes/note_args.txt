      FCFS = "fcfs"  # first come first serve
      LOF = "lof"  # longest output first
      RANDOM = "random"

  class SchedulePolicy:
      def calc_priority(self, waiting_queue: List[Req]):
          if self.policy == CacheAgnosticPolicy.FCFS:
              if self.enable_priority_scheduling:

                  )

- **FCFS implementation** (schedule_policy.py:280-289):
  ```python
  @staticmethod
  def _sort_by_priority_and_fcfs(waiting_queue, priority_sign: int):
      waiting_queue.sort(
          key=lambda x: (
              x.priority * priority_sign,
              x.time_stats.wait_queue_entry_time,  # FIFO order
          )
      )
  ```

- **Other policies**:

  - `dfs-weight` (Depth-First Search Weighted): Tree-traversal priority
  - `lof` (Longest Output First): Favors long-running generations
  - `priority`: Uses request priority field

- Prevents excessive compilation time for large batch sizes
- Works with `--cuda-graph-max-bs`: both limit which batch sizes get optimization

# Summary of Inference Flow

## Memory Allocation Flow
```
1. ModelRunner.__init__() receives mem_fraction_static=0.8
2. get_cell_size_per_token() calculates KV cell size based on kv_cache_dtype
   - fp8_e5m2: 1 byte per element
   - fp16: 2 bytes per element
3. init_memory_pool() calculates:
   - total_rest_memory = total_gpu_memory * 0.8 - model_weights
   - max_total_num_tokens = total_rest_memory / cell_size
4. TokenToKVPoolAllocator allocates pool of size max_total_num_tokens
```

## Batch Execution Flow
```
1. Scheduler receives requests via ZMQ
2. SchedulePolicy.calc_priority() orders waiting queue (fcfs = FIFO)
3. get_next_batch_to_run() selects batch based on:
   - Available KV cache
   - chunked_prefill_size=32768
4. ModelWorkerBatch created
5. TPWorker.forward_batch_generation() executes:
   - ForwardBatch prepared
   - Attention backend selected (flashinfer)
   - Quantized GEMM via gptq_marlin
   - CUDA graph replayed if batch_size <= 64
```

## Key Performance Optimizations in Your Configuration
1. **GPTQ Marlin**: 4-bit weights + specialized kernels
2. **FP8 KV Cache**: 50% memory reduction for KV storage
3. **FlashInfer**: Fast attention kernels vs Triton fallback
4. **CUDA Graph**: Eliminate kernel launch overhead for BS <= 64
5. **Chunked Prefill 32768**: Allow mixing prefill/decode
6. **No Radix Cache**: Simpler caching, no prefix matching overhead
