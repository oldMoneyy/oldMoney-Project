HYBRID ATTENTION ARCHITECTURE (SALA = Sparse Attention + Linear Attention)
================================================================================

The model uses a mixed attention strategy across its 32 layers:
  - 8 layers use "minicpm4" (sparse softmax attention with GQA)
  - 24 layers use "lightning-attn" (linear attention with full MHA)

Layer layout (M = minicpm4, L = lightning-attn):
  Layer  0: M    Layer  1: L    Layer  2: L    Layer  3: L
  Layer  4: L    Layer  5: L    Layer  6: L    Layer  7: L
  Layer  8: L    Layer  9: M    Layer 10: L    Layer 11: L
  Layer 12: L    Layer 13: L    Layer 14: L    Layer 15: L
  Layer 16: M    Layer 17: M    Layer 18: L    Layer 19: L
  Layer 20: L    Layer 21: L    Layer 22: M    Layer 23: L
  Layer 24: L    Layer 25: L    Layer 26: L    Layer 27: L
  Layer 28: L    Layer 29: M    Layer 30: M    Layer 31: M

Pattern: minicpm4 layers are placed at strategic positions —
  beginning (0), middle boundaries (9, 16-17, 22), and end (29-31) —
  acting as "anchors" with full softmax attention, while lightning-attn
  layers handle the bulk of computation with O(n) linear attention.
